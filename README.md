# ML-NLI-Faithfulness
# Explanation Faithfulness for Natural Language Inference

## Project Overview

This project evaluates whether attention-based explanations produced by transformer models are faithful to their predictions in Natural Language Inference (NLI).

The project compares:

- TF-IDF + Logistic Regression (Baseline)
- BART-MNLI Transformer

The e-SNLI dataset is used to evaluate model performance and explanation faithfulness.

## Dataset

e-SNLI Dataset

https://huggingface.co/datasets/esnli

## Models

- TF-IDF + Logistic Regression
- BART-MNLI

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Confidence Drop (Faithfulness)
